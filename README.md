# GitHub Flow Demo

Practice repository for Exercise 2: GitHub Flow.

## Workflow

1. Create a short-lived feature branch from main.
2. Commit changes and push the feature branch.
3. Open a pull request and request a review.
4. Update the code based on review feedback.
5. Approve and squash merge the pull request.
6. Sync main, clean up branches, and practice git stash.

## Roles

- Student A: repository owner and reviewer.
- Student B: contributor and pull request author.
